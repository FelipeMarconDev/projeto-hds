# Projeto HDS

## Objetivo

Solucionar um problema de uma empresa de médio porte que tem retrabalho causado por múltiplos sistemas dispersos.

## Tecnologias

- HTML
- CSS
- JavaScript

## Metodologia de Desenvolvimento

- Metodologia: SCRUM
- Por que escolhemos: Começamos com funcionalidades básicas e podemos evoluir conforme os usuários da empresa dão feedback. Permite realizar o desenvolvimento em etapas menores que podem ser testadas em períodos de uma semana.

## Como vamos trabalhar

- Fluxo: Backlog -> A Fazer -> Em Andamento -> Revisão -> Concluído
- Rotina de Acompanhamento: Será realizado por meio de atualização contínua do quadro de tarefas pelos integrantes. Caso haja novas demandas, elas serão discutidas pela equipe e adicionadas no Backlog.
- Ferramenta de Tarefas:
    - Trello: https://trello.com/b/DtzmjePO/projeto-hds

## Definição de Pronto (DoD)

- Funciona no navegador sem erros visíveis
- Estrutura HTML organizada/semântica
- JS implementado conforme o esperado no MVP
- Versionado no repositório com commit(s) coerente(s)
- Atualizado no quadro de tarefas (status e responsável)

## Como Executar

- Acessar: https://felipemarcondev.github.io/projeto-hds/
- Clonar o repositório e utilizar a funcionalidade *Go Live* no VS Code.
- Clonar o repositório e executar as seguintes etapas:
    - No terminal, na pasta raiz do projeto: `python -m http.server 8000`
    - No navegador Google Chrome, digitar a URL `localhost:8000`

## Melhorias do Sistema

- Exibição das solicitações foram alteradas de texto para tags, e  os detalhes foram ocultados até que o usuário clique na solicitação.
- Inclusão de gráficos para facilitar a compreensão da origem e destino das solicitações. Acompanhar resultados, identificação de problemas e ajudar na tomada de decisões.
- Campo de descrição foi criado para a conclusão do chamado, permitindo que seja dado um feedback ao solicitante responsável.
