# Checklist Boas Práticas

1. Comentar o código
2. Atualizar o progresso no quadro de tarefas
3. Organização das pastas na raíz do projeto
4. Separação do código por responsabilidades (eg. classes, manipulação do DOM, execução principal, ...)
5. Indentação do código para clareza de entendimento, facilita visualizar o aninhamento de funções e declarações
6. Manter a organização do ambiente de desenvolvimento
